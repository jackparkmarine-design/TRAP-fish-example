UPDATING THE GITHUB BRANCH TO V14
================================
New in v14: a Lock button (top right) that locks the screen for wiping salt off;
taps and keys are ignored until someone holds "Hold here 1.5 s to unlock" with a
still finger (a wiping motion does not unlock). An orange Clear button inside the
length display clears the whole length in one tap.
From v13: a Depth (m) box for each trap on the Positions page (exported as depth_m
and unit_depth_m); Time out now fills itself in when the first fish or Empty trap is
entered for a trap (marked AUTO, never overwrites a time you set; exported with
time_out_auto Y/N).
From v12: fixes updates. Previously an iPad could say "Update downloaded" but keep
showing the old screens, because it re-used an old copy of the app from its web
cache. Updates now always fetch fresh files. From v12 on, a green "Update
downloaded · tap to restart" button appears, and Setup has "Check for updates".
From v11: minimum length check is now 200 mm (a shorter fish needs a second tap
on Enter); the Depredation section is removed and the remaining buttons are larger;
new discard reason RG (regurgitated), which sets release condition DD automatically;
a fish with no length now needs a second tap on Enter instead of being blocked.
From v10: the numbers on the species buttons (data entry) now count the
current trap / drop / angler only; the Full list still shows whole-survey totals.
From v9: a camera button for Unidentified fish (several photos per fish, stored
on the iPad, included in full backups and restores, "Save photos" on the Export
page, photo_files column in the CSV); a Delete button on every Full list row with a
second confirmation ("Yes, delete") before anything is removed.
From v8: the green button on the Survey page reads "Add Survey".
From v7 (data safety): every fish is now saved in two independent stores on
the iPad (the main store holds hundreds of MB, so it no longer fills after ~3 days);
a red banner if a save ever fails (entry is never blocked); a backup status button
in the top bar (green / amber / red, tap it to back up); one-file Full backup and
Restore (Setup); marking a station complete now saves the full backup plus that
station's CSV. Existing data moves into the new store automatically the first
time v7 opens. It replaces whatever version is on the branch now (v1 to v13). Survey data already on the iPads is kept.

A. UPDATE THE BRANCH (on a computer)
1. Unzip catch-logger-v14.zip.
2. Open your repository on github.com (e.g. github.com/YOUR-USERNAME/catch-logger).
   Check the branch selector above the file list says "main".
3. Click "Add file" > "Upload files".
4. Drag in ALL the files from the zip (not the folder). Same-named files are replaced.
5. Under "Commit changes" type:  Release v14   then click "Commit changes".
6. The file list should now show: index.html, sw.js, manifest.webmanifest,
   icon-180.png, icon-192.png, icon-512.png, README.txt, UPDATE-BRANCH.txt.
   If an old UPDATE-TO-V2.txt is there, open it > "..." menu > Delete file. (It is harmless.)
7. Wait 1-2 minutes. Settings > Pages should show "Your site is live".
8. Check: open  https://YOUR-USERNAME.github.io/catch-logger/sw.js  in a browser.
   It must say  const VERSION = 'catch-logger-v14'.
   Still showing an older number? Wait a few minutes and refresh; GitHub can lag.

B. UPDATE EACH IPAD (with internet, after exporting today's data)
IF THE IPAD IS ON v11 OR EARLIER: open the app, wait 20 seconds, close it fully
(swipe the card away), reopen. Repeat once if Setup does not show v14.
FROM v12 ON:
    Open the app with internet. A green "Update downloaded · tap to restart"
    button appears within a few seconds; tap it. Or use Setup > Check for updates.
12. Check your stations and fish records are still there.

If an iPad is still on an old version after two open/close cycles:
    Export all stations, delete the home-screen icon, open the address in
    Safari and Add to Home Screen again. Deleting the icon deletes the data on
    that iPad, so export first.

NEXT TIME
    For any later change, edit the files and change catch-logger-v14 to
    catch-logger-v15 in sw.js (and APP_VERSION in index.html), then repeat A and B.
